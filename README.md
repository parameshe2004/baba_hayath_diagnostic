# Baba Hayaath Diagnostic Centre (BHDC) — Web Application

Modern, high-performance clinical diagnostic web application for Baba Hayaath Diagnostic Centre (Puttaparthi, Andhra Pradesh). Built with Next.js 16 (App Router), React 19, TypeScript, and Tailwind CSS v4.

## Features
- **SweetDreamss.in Architecture**: Single-layer transparent glass navbar, ultra-light warm yellow-ivory canvas (`#FAF7F2`), Playfair Display serif typography, and clean elevated cards.
- **BHDC Emblem Branding**: Royal Deep Blue (`#0B3B60`) & Emerald Green (`#10B981`).
- **Health Checkup Packages**: ₹1,399 Basic Checkup & ₹2,999 77-Test Checkup Package.
- **Major Tests Showcase**: Displays 9 most requested tests on the homepage.
- **Comprehensive Booking Portal**: Schedule appointments or doorstep home sample collection for any test in the lab directory.
- **Hospital-Grade Analyzers**: Erba XL-200, Snibe MAGLUMI X3 (CLIA), and Erba H 560 (Malaria Flagging) specifications.

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
